# EEW Web / VR災害情報センター

公開サイト: **https://neco222.github.io/EEW-Web/**

[kotoho7 / リアルタイム地震ビューアー](https://github.com/kotoho7/scratch-realtime-earthquake-viewer-page) v1.6.3+5をベースにした改造版です。元のScratchプロジェクト、画像・音声、地震・津波表示、履歴、読み上げ、設定を保持し、追加機能を独立したJavaScriptモジュールとして重ねています。

## この版の追加内容

- 新しい緊急地震速報・地震情報を受信すると、震源から300km以内の登録ライブカメラを近い順に選び、音声を消して1台だけ再生します。全国10地域・25配信を収録し、2026年10月20日に公式配信のLIVE・埋込可を確認しています。設置座標ではなく撮影対象地域の代表座標を使うため、距離は概算です。
- カメラは右側の専用欄、縦長の画面では下の専用欄を確保し、元の震度情報や地震履歴に重ねません。小さい画面では映像を読み込まず提供元リンクに縮小します。「カメラ」から開閉・自動表示の切替・別のカメラへの変更ができます。初期履歴・履歴の選択・続報・リプレイでは勝手に開き直しません。起動時の進行中EEWは3分以内だけ自動表示の対象です。EEW終了・消失から約30秒、通常の地震情報は最後の続報から2分、手動表示は開始から2分で閉じます。EEWの新情報が5分途絶えた場合も閉じ、取消・縮小・ページ非表示では映像を破棄します。
- カメラはYouTubeの公式プレーヤーで配信元から直接再生し、APIキーや追加サーバーは不要です。通常の待機中にはプレーヤーを読み込みません。配信終了・埋込禁止では次の近傍候補を試し、再生できない場合も提供元で確認できます。配信停止・動画ID変更・ライブ配信の録画化は起こり得るため、カタログの確認日は常時LIVEの保証ではありません。`docs/live-cameras.js` の出典・確認日・IDを更新してください。
- P2P地震情報のユーザーによる「揺れた」報告を「コミュニティ投稿」として表示します。新着時だけ地域付近に「＋○件」の透過したガラス調の吹き出しを約3秒表示します。地図の移動・拡大縮小に追従し、震度アイコン・震源・他の吹き出しと重ならない空間へ引き出し線で移動します。空いた場所がない場合は無理に重ねません。
- 新しい個別投稿が1件でもあれば、投稿地域の代表位置へ地図を移動します。倍率を保ち、EEW・津波・新しい地震情報・強震検出・既存の自動移動や手動操作を優先します。元の「自動カメラ」がOFFの場合も移動しません。短時間の近隣投稿はまとめ、移動は最短3秒間隔です。手動操作後30秒、最新地震情報の発表・更新後2分、過去の地震や別タブの表示中、画面切替中には投稿による移動を行わず、見送った投稿を後から再実行しません。履歴補完・集計・重複・古い投稿では移動しません。詳細欄の「投稿地域へ地図移動」で切り替えられます。
- 直近10分の地域別件数・接続状態は下端の小さな欄から確認できます。詳細を開くと専用の表示領域を確保し、元の震度画面に重ねません。履歴の初回読み込み・再接続の補完・重複データは新着の吹き出しを出しません。
- 個別の「揺れた」投稿ログはカメラとは独立して常時表示し、カメラを閉じた時・自動表示OFF・近くに配信がない時・再生できない時も残します。右側の専用欄で、カメラ表示中は映像の下に配置します。狭い画面では下に投稿欄を確保し、元の地震情報に重ねません。集計詳細を開いた時は、その中の先頭にログを移します。直近10分・最大120件を時刻・地域とともに1件ずつ新しい順で表示し、履歴補完分は「履歴」と区別します。累積集計から個別投稿を作りません。過去の行をスクロール中は位置を保ち、「最新へ」で追従を再開できます。既存の接続と履歴取得を共有し、投稿の集中時も更新をまとめます。
- 新着の「揺れた」報告でも、投稿地域の代表点から300km以内の登録カメラを自動表示します。履歴・重複・古い報告・デモでは開かず、緊急地震速報や新しい地震情報を優先します。投稿でカメラを次々切り替えず、表示開始から約2分で閉じます。映像は地域の様子であり、その地点の揺れ・震度・震源を示すものではありません。
- 表示位置はP2P地震情報の公式地域コード表にある代表座標です。個人の正確な位置・震度・震源を示しません。報告がない場合は0件、場所の内訳がない場合は地図に推測して置かず件数だけを表示します。
- 地震感知情報 `561` と累積集計 `9611` を扱い、ID/UIDの重複、再接続時の履歴とライブ配信の重複、累積集計の二重加算を防止します。新着の吹き出しは `561` の個別投稿だけを数え、`9611` は直近10分の合計更新に使います。古い報告は発信時刻をもとに除外します。
- VR災害情報センターの背景透過ロゴを、右下の元のバージョン表記と同じ幅・位置へ重ねています。ロゴ読込みに失敗したときは元のバージョン表記に戻ります。地図操作は妨げません。
- 地図の描画分岐と最終画面の描画を平均15fpsに制限します。VMの実行速度、受信、時計、読み上げ、自動カメラの計算は元の設定で動かします。描画後も1のままだった変更フラグは描画の入口で消費し、EEWのP/S波・震源の点滅・津波表示は15fpsの継続更新で維持します。
- 地図背景だけを独立したペンレイヤへキャッシュし、カメラ・画面寸法・配色・背景SVGの読込や変更に合わせて再作成します。地図プロシージャ内の計算は省かず、動的な震度や津波を背景へ固定しません。同じ描画効果の再設定と最前面への重複移動も省きます。元の `index.js` と `assets/project.json` は編集していません。
- 公開時のプロジェクトJSONのダウンロード量を5.88 MBから0.77 MBへ圧縮しました（86.9%減、復元後の全バイト一致を検証）。対応ブラウザーでは標準のDecompressionStreamで展開し、非対応ブラウザーは元のJSONを利用します。上流のアクセス解析タグを除去し、キャッシュの対象パスを設置先に追従させ、他のアプリのキャッシュを消さない構成にしています。

P2Pの受信にはAPIキーは必要ありません。元の地震・津波機能は上流と同じ外部配信サーバーに依存します。キャッシュは一度読み込んだ素材の再利用を補助しますが、最新情報の受信にはインターネット接続が必要です。

公開APIの地震感知情報には利用者のコメント本文が含まれないため、吹き出しは地域名と新着件数を表示します。気象庁電文の付加文を利用者コメントとして表示することはありません。

[CPUのみの描画環境での比較測定・変更の仕組み](PERFORMANCE.md)を記録しています。

## 開発・検証・公開

Node.js 22以上を使用します。Web版の開発・テスト・公開用生成には追加パッケージのインストールは不要です。

```text
npm run dev       # http://127.0.0.1:4173/ で元データのまま確認
npm test          # 報告集計・投影・描画最適化・通信・キャッシュの回帰テスト
npm run build     # docs/ を保持して dist/ に公開用データを生成
npm run preview   # http://127.0.0.1:4174/ で公開用データを確認
```

ファイルを直接ダブルクリックせず、HTTP/HTTPSで開いてください。`main`へのpush時に `.github/workflows/pages.yml` が検証・生成を行い、GitHub Pagesへ公開します。設定はPagesのSourceを **GitHub Actions** とします。

描画の互換性を調べる場合は `?cpuRender=0` で開くと、地図の15fps制限と背景キャッシュを適用せずに起動します。保存済みの設定や受信データは消しません。未対応のプロジェクト構造・描画APIでは、最適化を適用せず元の動作を続けます。

既存のデスクトップ版生成は `publish` ワークフローを手動実行する形で残しています。Webの更新ごとに3環境のデスクトップ版を生成する処理は走りません。

`?communityDemo=1` をURL末尾につけると、通信せずにサンプルの揺れ報告を重ねて表示できます。「デモ表示・実際の報告ではありません」と表示される検証用モードです。URLパラメーターがない通常表示ではサンプル報告を混ぜません。

## 概要

リアルタイムに地震・津波情報を閲覧することができます。  
基本的に操作は不要で、全自動でリアルタイムに受信した情報を表示します。

アプリ内タブごとに、以下の情報を閲覧することができます。

- **地震情報**

  地震発生後数分で気象庁から発表される **震度速報**, **震源情報**, **地震情報**, **長周期地震動情報** をリアルタイムに更新して表示します。この地震情報はTVや気象庁HPで閲覧できる地震情報と同様です。  
  最新地震の他、過去9件の地震履歴を見ることができます。

- **リアルタイム情報 (緊急地震速報)**

  地震発生直後に、気象庁から発表される **緊急地震速報（予報）**, 防災科研の強震モニタを元にした **リアルタイム震度** を表示します。  
  これらの情報は**非常に高いリアルタイム性**がありますが、予測値や相当値を含むため**参考値**であることに留意が必要です。

- **津波予報・津波観測情報**

  地震等に伴い気象庁から発表される **大津波警報**, **津波警報**, **津波注意報**, **津波予報** と、実際に津波を観測した際の **津波観測に関する情報** をリアルタイムに更新して表示します。  
  各地の津波予想高さや到達予想時間、観測された津波の高さを見ることができます。

このアプリケーションで使用されている気象庁のリアルタイム電文については、基本的に [Project DM-D.S.S (dmdata.jp)](https://dmdata.jp/) からデータを受信しています。
WebSocketによるサーバーへの常時接続を行うため、気象庁が発表する情報を即時的に受信することが可能です。

## 緊急地震速報の注意事項

このプロジェクトでは、高度利用者向けの **緊急地震速報（予報）** が表示されます。以下の特徴を踏まえて情報を活用してください。

- 地震発生後、数秒で情報が作成されるため、誤報が発生することがあります。
- 地震検知直後の情報は震源やマグニチュード、予測震度の精度が低いことがあります。
- 通常でも推定震度は1階級程度の誤差があります。
- 深さ150kmより深い地震の場合、予想最大震度は発表されません（※実際の揺れに基づいて発表される場合もあります）。
